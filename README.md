# VAPA Campus Public Art — SDUSD pilot (updated with artwork photographs)

A standalone prototype, separate from the independent Teach Public Art app.

## Included
- Three Zamorano murals: Monty Montgomery, Santos Orellana, Maxx Moses
- Three artist-matched Google Slides lessons, linked from cards and lesson library
- Three optimized mural photographs in `assets/`
- School search and map embed (one pilot school)

## Preview and publish
Open `index.html` locally to preview (internet required for map and Google Slides). To publish, create a **separate** GitHub repository `vapa-campus-public-art`, upload the **contents** of this directory (not the ZIP), and enable GitHub Pages under Settings → Pages, branch `main`, folder `/ (root)`.

## Update
Edit `data.js` to add schools, artists, photos, and lesson links. Keep photo assets under `assets/`. Future Google Sheets syncing requires an approved public data feed; this prototype uses static records.

## Before deployment
Confirm image reproduction rights/credits, district VAPA branding approval, Google Slides access permissions, and artwork metadata. The embedded map currently shows only the selected campus, not a districtwide proximity search. No student information or analytics are collected.
